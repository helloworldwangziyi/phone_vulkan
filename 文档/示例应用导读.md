# 示例应用导读

示例 App 是 Android 与 iOS 共用的一份 C++ Widget 应用。

## 启动

| 事件 | App 行为 |
|---|---|
| SurfaceChanged | 更新设计像素换算并调用 setViewportSize |
| EngineReady | runApp(makeWidget<HomePage>(), AppOptions) |
| SurfaceDestroyed | shutdownApp |
| BackPressed | 导航栈 pop；栈底不消费，交还平台壳收尾 |
| SafeAreaChanged | setSafeAreaInsets，根视图内缩避开状态栏/刘海/手势条 |

平台壳只翻译 surface、VSync、pointer 和系统事件（返回/安全区），不创建页面或控件。

## 首页

HomePage 是 StatefulWidget，HomePageState 持有面板开关、详情页序号、行情数据
和请求取消标志。

build 只描述结构：

~~~cpp
auto page = std::make_unique<Column>(widgetList(
    padding(..., sizedBox(..., container(...))),
    center(sizedBox(..., button(...))),
    expanded(
        padding(..., scrollView(column(rows), contentHeight)))));
~~~

这里没有 create、layout、destroy，也没有 View 句柄。setState 后 Element 自动
更新同位置的 Widget，ScrollView 的 offset 保留在原 View 中。

## 详情页

DetailPage 是 StatelessWidget，variant 是不可变配置。两行卡片使用：

~~~cpp
row(
    expanded(padding(gap, container(colorA))),
    expanded(container(colorB)))
~~~

按钮通过当前 BuildContext 跳转：

~~~cpp
Navigator::of(context).push(
    makeWidget<DetailPage>(variant + 1), true);
~~~

## 自定义绘制

面板和详情页主视觉使用 PaintContext。绘制函数只处理局部尺寸和颜色：

~~~cpp
[](PaintContext& paint) {
    const Size size = paint.size();
    paint.drawTriangle(...);
}
~~~

坐标平移与父级裁剪由框架处理。

## 异步行情

HomePageState 在 onDidEnter 发起后台任务。任务结束后用 postUi 回 UI 线程，
先检查 mounted 和取消标志，再 setState。onWillLeave 与 dispose 都会设置取消
标志，因此迟到任务不会访问已经销毁的 State。

## 主题

主题按钮更新 token，调用 Navigator::setStyle 更新导航栏，再由 EventBus 广播。
HomePageState 的 listen 订阅随 State 生命周期自动取消。
