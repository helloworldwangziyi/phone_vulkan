# 源码导读

## 文件命名

自研 C/C++、资源和脚本直接以功能命名，例如 `widget_tree.h`、
`flex_layout.cpp`、`android_jni_bridge.cpp`。Java 与 Objective-C 类文件
遵循语言惯例的大驼峰类名，例如 `NativeBridge.java`、`ViewController.mm`。
`CMakeLists.txt`、`AndroidManifest.xml`、`Info.plist` 等平台固定名称不改。

## UI 公共接口

| 文件 | 说明 |
|---|---|
| core/include/evk/ui/ui_application.h | runApp、shutdownApp、setViewportSize |
| core/include/evk/ui/widget_tree.h | Widget、Element、BuildContext、State 与布局 Widget |
| core/include/evk/ui/navigation/navigation_stack.h | Navigator、NavigationStyle |
| core/include/evk/ui/event_bus.h | EventBus、RAII EventSubscription、postUi |
| core/include/evk/ui/render_view.h | 内部 View、ViewRef、PaintContext |
| core/include/evk/ui/pointer_input.h | PointerEvent 与手势分发 |
| core/include/evk/ui/paint_canvas.h | CPU 顶点流与 clip batch |
| core/include/evk/ui/font_engine.h | TTF 解析、字形 atlas、多字体回退 |
| core/include/evk/ui/texture_store.h | 统一 RGBA 纹理仓库（字形页 + 业务位图） |

| core/src/ui/view/button_control.cpp | pressed/cancel/up 状态机 |

| core/src/ui/render_view.cpp | View 树、PaintContext、帧构建 |
| core/src/ui/pointer_input.cpp | 命中、点击、pan winner 与速度估计 |

## 示例

- samples/app/app_entry.cpp：surface 事件映射到 setViewportSize、runApp、shutdownApp。
- samples/app/home_page.cpp：StatefulWidget、State、异步数据、事件订阅。
- samples/app/detail_page.cpp：StatelessWidget、组合布局、Navigator push。
- samples/app/app_fonts.cpp：内嵌字体注册（Roboto + Noto Sans SC 双 CJK 字重）。
- samples/app/app_images.cpp：程序化位图登记（径向渐变徽章，走 drawImage 通道）。
- tests/ui_runtime_test.cpp：新 SDK 的可执行行为规格。

## 推荐阅读顺序

1. samples/app/detail_page.cpp

3. core/include/evk/ui/widget_tree.h
4. core/src/ui/widget_tree.cpp
5. core/src/ui/navigation/navigation_stack.cpp
