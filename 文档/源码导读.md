# 源码导读

> 按推荐阅读顺序排列，仅覆盖当前已落地的代码。

## 1. 公共核心 `core/`

| 文件 | 说明 |
|---|---|
| `core/include/evk/event.h` | 事件定义：`EventId` 枚举、各事件 data 结构体、`EventFunc` 回调类型、`setEventFunc` / `dispatchEvent` 声明 |
| `core/src/event.cpp` | 事件分发实现：全局回调注册与转发（无回调时丢弃） |
| `core/include/evk/log.h` | 日志封装：spdlog header-only，`evk::log::init(tag)` + `EVK_LOG*` 宏 |
| `core/include/evk/platform.h` | 平台抽象 `IPlatform`：创建 VkSurface、查询尺寸、日志回调 |
| `core/include/evk/renderer.h` | `evk::Renderer` 公开 API |
| `core/src/renderer.cpp` | Vulkan 渲染器完整实现（三角形演示） |
| `core/src/platform_android.cpp` | Android 平台实现：ANativeWindow 建 surface、日志路由进 spdlog |

## 2. 安卓薄壳 `platform/android/`

| 文件 | 说明 |
|---|---|
| `java/com/estarx/vulkan/NativeBridge.java` | JNI 声明：surface 生命周期 4 个 + `nativeOnTouch` |
| `java/com/estarx/vulkan/VulkanSurfaceView.java` | SurfaceView：生命周期与触摸事件转发到 JNI |
| `cpp/bridge.cpp` | JNI 实现：创建/销毁 Renderer，事件解包 → `dispatchEvent` |

## 3. 演示 App `samples/android/`

- `app/src/main/java/com/estarx/vulkansample/MainActivity.java` — 仅 `setContentView`
- `app/src/main/res/layout/activity_main.xml` — 布局中放置 `VulkanSurfaceView`
- `app/src/main/cpp/CMakeLists.txt` — 把 bridge + core 编进 `libestarx_vulkan.so`

## 4. 构建

- 根 `CMakeLists.txt` — 桌面/框架级构建（core 静态库 + Android 平台库）
- `samples/android/app/build.gradle` — App 模块：CMake 外联、ABI 仅 arm64-v8a、Java 源加入 `platform/android/java`
- `third_party/spdlog/` — header-only 日志库（include/ + LICENSE）
