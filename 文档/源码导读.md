# 源码导读

> 按推荐阅读顺序排列，仅覆盖当前已落地的代码。

## 1. 公共核心 `core/`

| 文件 | 说明 |
|---|---|
| `core/include/evk/event.h` | App 生命周期：`AppStart` / `SurfaceChanged` / `SurfaceDestroyed` |
| `core/src/event.cpp` | 生命周期单入口注册与转发 |
| `core/include/evk/log.h` | 日志封装：spdlog header-only，`evk::log::init(tag)` + `EVK_LOG*` 宏 |
| `core/include/evk/platform.h` | 平台抽象 `IPlatform`：创建 VkSurface、查询尺寸 |
| `core/include/evk/renderer.h` | `evk::Renderer` 公开 API |
| `core/src/renderer.cpp` | Vulkan 渲染器：动态顶点缓冲 + push constant 正交投影，渲染一帧 `Canvas` |
| `core/src/platform_android.cpp` | Android 平台实现：ANativeWindow 建 surface |
| `core/include/evk/ui/view.h` | 视图树：`Rect`/`Color`/`View`，actual 重算、命中测试 |
| `core/src/ui/view.cpp` | 视图树实现 |
| `core/include/evk/ui/input.h` | 跨平台 `PointerEvent`（含时间戳）与 UI 输入入口 |
| `core/src/ui/input.cpp` | 命中测试、点击取消、滑动目标选择、Begin/Update/End 分发与滑动速度估计 |
| `core/include/evk/ui/animator.h` | 逐帧动画注册/缓动函数（core 内部 API） |
| `core/src/ui/animator.cpp` | VSync 逐帧动画驱动，供转场/惯性/回弹使用 |
| `core/include/evk/ui/controls/` | App 可用的 Button / ScrollView / Navigation C ABI |
| `core/src/ui/controls/` | 控件 pressed、点击、滚动惯性回弹与导航栈/转场实现 |
| `core/include/evk/ui/canvas.h` | 帧画布：顶点流 + clip 栈，供 renderer 一次性提交 |
| `core/src/ui/canvas.cpp` | 画布实现 |
| `core/include/evk/esx_view.h` | 视图 ABI：`esx_view` 句柄、`esx_create_view`/`esx_draw_*` 等 |
| `core/src/esx_view.cpp` | ABI、回调绑定与帧构建（`esxBuildFrame`） |
| `core/include/evk/render_loop.h` | dirty 请求与平台 VSync `beginFrame` |
| `core/src/render_loop.cpp` | 合并 dirty 请求，只在 VSync 提交帧 |

## 2. 安卓薄壳 `platform/android/`

| 文件 | 说明 |
|---|---|
| `java/com/estarx/vulkan/NativeBridge.java` | surface、VSync 与 Pointer 的 JNI 声明 |
| `java/com/estarx/vulkan/VulkanSurfaceView.java` | SurfaceView + Choreographer 薄壳 |
| `cpp/bridge.cpp` | Renderer 生命周期、PointerAction 翻译及 VSync 转发 |

## 3. 公共 App `samples/app/`

- `app_main.cpp`：唯一 App 生命周期入口；创建 Navigation 根视图并接入页面栈。
- `app_metrics.*`：窗口尺寸与设计像素换算。
- `app_theme.*`：自建颜色系统：语义化设计 token，深色/浅色双主题可切换。
- `app_ui.h`：`appRebuildUi()`，切换主题后销毁并按新主题重建视图树。
- `main_page.*`：首页：渐变面板、详情页/主题按钮、ScrollView 演示。
- `detail_page.*`：详情页：演示导航栏返回按钮与左缘滑动返回，可多实例。
- `samples/android/` 只保留 Activity、资源和链接公共 App 的 CMake 入口。

## 4. 测试 `tests/`

- `ui_runtime_test.cpp`：不依赖 Vulkan 的桌面 assert 测试，直接链接 core
  源码，覆盖 dirty 帧合并、输入分发、滚动惯性/回弹、导航栈/转场/左滑返回。
- `run_ui_runtime_test.sh`：用系统 clang++（macOS 走 xcrun）编译并运行。

## 5. 构建

- 根 `CMakeLists.txt` — 桌面/框架级构建（core 静态库 + Android 平台库）
- `cmake/embed_shaders.cmake` — 用 glslc 把 `core/shaders/*.vert/.frag` 编译并嵌入为 C 数组
- `samples/android/app/build.gradle` — App 模块：CMake 外联、ABI 仅 arm64-v8a、Java 源加入 `platform/android/java`
- `third_party/spdlog/` — header-only 日志库（include/ + LICENSE）
- `third_party/glm/` — header-only 数学库（矩阵/向量，renderer 投影用）
