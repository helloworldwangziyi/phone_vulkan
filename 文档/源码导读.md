# 源码导读

## 文件命名

自研 C/C++、资源和脚本统一使用 `zy_功能`，例如 `zy_widget_tree.h`、
`zy_flex_layout.cpp`、`zy_android_jni_bridge.cpp`。Java 与 Objective-C 类文件
遵循语言惯例使用 `Zy功能`，例如 `ZyNativeBridge.java`、
`ZyViewController.mm`。`CMakeLists.txt`、`AndroidManifest.xml`、`Info.plist`
等平台固定名称不改。

## UI 公共接口

| 文件 | 说明 |
|---|---|
| core/include/evk/ui/zy_ui_application.h | runApp、shutdownApp、setViewportSize |
| core/include/evk/ui/zy_widget_tree.h | Widget、Element、BuildContext、State 与布局 Widget |
| core/include/evk/ui/navigation/zy_navigation_stack.h | Navigator、NavigationStyle |
| core/include/evk/ui/zy_event_bus.h | EventBus、RAII EventSubscription、postUi |
| core/include/evk/ui/zy_render_view.h | 内部 View、ViewRef、PaintContext |
| core/include/evk/ui/zy_pointer_input.h | PointerEvent 与手势分发 |
| core/include/evk/ui/zy_paint_canvas.h | CPU 顶点流与 clip batch |

## UI 实现

| 文件 | 说明 |
|---|---|
| core/src/ui/zy_ui_application.cpp | 根 Navigator 与 viewport 生命周期 |
| core/src/ui/zy_widget_tree.cpp | Element mount/update/unmount、State 重建、组合 Widget |
| core/src/ui/navigation/zy_navigation_stack.cpp | Route 所有权、生命周期、转场、左缘返回 |
| core/src/ui/layout/zy_flex_layout.cpp | Row/Column 主轴分配 |
| core/src/ui/controls/zy_button_control.cpp | pressed/cancel/up 状态机 |
| core/src/ui/controls/zy_scroll_control.cpp | 拖动、惯性、橡皮筋与回弹 |
| core/src/ui/zy_render_view.cpp | View 树、PaintContext、帧构建 |
| core/src/ui/zy_pointer_input.cpp | 命中、点击、pan winner 与速度估计 |
| core/src/ui/zy_event_bus.cpp | scoped 事件和跨线程任务队列 |
| core/src/ui/zy_animation_scheduler.cpp | std::function 逐帧动画 |

## 示例

- samples/app/zy_app_entry.cpp：surface 事件映射到 setViewportSize、runApp、shutdownApp。
- samples/app/zy_home_page.cpp：StatefulWidget、State、异步数据、事件订阅。
- samples/app/zy_detail_page.cpp：StatelessWidget、组合布局、Navigator push。
- tests/zy_ui_runtime_test.cpp：新 SDK 的可执行行为规格。
