# 构建指南

## 环境要求

| 项 | 说明 |
|---|---|
| Android Studio | 任意近期版本，内置 JBR 作为 Gradle JDK |
| Android SDK | `C:\Users\Administrator\AppData\Local\Android\Sdk`（已写入 `local.properties`） |
| NDK / CMake | 通过 SDK Manager 安装；CMake 固定 3.22.1（见 app 模块 `build.gradle`） |
| JDK | 命令行构建需手动指定 JBR（见下）；AS 内构建用默认 JBR 即可 |

工程约束：`compileSdk 34`、`minSdk 24`、ABI 仅 `arm64-v8a`。

## 命令行构建

Windows（Git Bash）下必须先指定 JAVA_HOME（系统未安装独立 JDK）：

```bash
export JAVA_HOME="C:\\Users\\Administrator\\Files\\android_studio\\jbr"
./gradlew :samples:android:app:assembleDebug
```

产物：`samples/android/app/build/outputs/apk/debug/app-debug.apk`

## Android Studio 构建

直接打开项目根目录，等待 Gradle Sync 完成后 Run。

注意：工程结构（模块/目录）发生变更后，AS 可能因 `.idea` 旧缓存 sync 失败。
解决办法：关闭 AS，删除 `.idea/` 与 `.gradle/` 后重新打开。

## 运行与调试

### 模拟器

```bash
"$ANDROID_SDK/emulator/emulator.exe" -avd Medium_Phone_API_36.0
adb install -r samples/android/app/build/outputs/apk/debug/app-debug.apk
```

### 真机（无线调试）

开发者选项 → 无线调试 → 配对码配对：

```bash
adb pair <IP:配对端口>      # 输入手机显示的配对码
adb connect <IP:连接端口>   # 端口见无线调试首页
```

> 荣耀/华为机型注意：若 USB 连接时 `adb devices` 为空，多为
> "允许 HiSuite 通过 HDB 连接" 抢占了调试通道，关闭该选项后重新插拔即可。
> 无线调试不经过 USB/HDB，可直接绕开此问题。

### 日志

native 日志经 spdlog 输出到 logcat，tag 为 `estarx-vulkan`：

```bash
adb logcat -s estarx-vulkan
```

## HarmonyOS

鸿蒙薄壳位于 `platform/hongmeng/cpp`（NAPI 桥接 + `VK_OHOS_surface` 平台适配），
示例工程在 `samples/hongmeng`（DevEco 工程，stage 模型，API 17 验证）。

### 环境要求

| 项 | 说明 |
|---|---|
| DevEco Studio | 5.0 及以上，内置 OpenHarmony SDK（本工程按 API 17 / 5.0.5 配置） |
| glslc | 需在 PATH 中（shader 嵌入，与 Android 构建同一机制） |
| 签名 | `build-profile.json5` 的 `signingConfigs` 留空，IDE 内 File → Project Structure → Signing Configs 自动签名 |

### DevEco Studio 构建

用 DevEco Studio 打开 `samples/hongmeng` 目录（注意不是仓库根目录），
等待 Sync 完成后 Run。native 部分由 `entry/src/main/cpp/CMakeLists.txt`
驱动，编译产物为 `libestarx_vulkan.so`（同时包含壳、core 与 samples/app）。

### 命令行构建

使用 DevEco 自带的 hvigor wrapper（`tools/hvigor/bin/hvigorw`），
在 `samples/hongmeng` 目录下执行：

```bash
export NODE_HOME="/Applications/DevEco-Studio.app/Contents/tools/node"
export DEVECO_SDK_HOME="/Applications/DevEco-Studio.app/Contents/sdk"
/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw \
    assembleHap --mode module -p product=default --no-daemon
```

产物：`samples/hongmeng/entry/build/default/outputs/default/entry-default-unsigned.hap`
（命令行不签名，装真机前需在 DevEco 里配置签名。）

### 日志

native 日志经 spdlog → hilog 输出（tag `estarx-vulkan`）：

```bash
hdc shell hilog | grep estarx-vulkan
```
